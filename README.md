# 项目说明 - My IoT Project (STM32F103)

## 1. 项目概述

本项目是一个基于 STM32F103C8 微控制器的 IoT 嵌入式系统项目，使用 Rust 语言和 Embassy 异步框架开发。该项目实现了一个完整的环境监测和控制系统，能够采集温湿度、光照和土壤湿度等环境数据，并通过执行器控制设备状态。

### 技术栈

- **开发语言**: Rust
- **异步框架**: Embassy
- **硬件平台**: STM32F103C8 (ARM Cortex-M3)
- **通信协议**: SPI、I2C、GPIO、UART

## 3. 核心功能模块

### 3.1 传感器数据采集

#### DH11温湿度传感器 (GPIO)

- **驱动文件**: `src/dht11.rs`
- **功能**: 采集环境温度和湿度数据
- **采样频率**: 约每2秒采样一次
- **通信方式**: 单总线通信协议

#### BH1750光照传感器 (I2C)

- **驱动文件**: `src/bh1750.rs`
- **功能**: 采集环境光照强度数据
- **采样频率**: 约每2秒采样一次
- **通信方式**: I2C总线

#### 土壤湿度传感器 (ADC)

- **驱动文件**: `src/soil.rs`
- **功能**: 采集土壤湿度数据
- **采样频率**: 约每2秒采样一次
- **通信方式**: ADC模拟输入

### 3.2 执行器控制

#### 继电器控制

- **驱动文件**: `src/actuator.rs`
- **功能**: 控制水阀、风扇、灯光和蜂鸣器
- **控制方式**:
  - 开关控制 (On/Off)
  - 脉冲控制 (Pulse，定时关闭)

### 3.3 显示功能

#### ST7735S屏幕 (SPI)

- **驱动文件**: `src/st7735.rs`
- **功能**: 显示传感器数据和系统状态
- **分辨率**: 128x160像素
- **支持功能**: 图形绘制、中文显示、ASCII字符显示

### 3.4 数据通信

#### UART通信

- **驱动文件**: `src/uart.rs`
- **功能**: 与外部设备进行数据通信
- **波特率**: 115200
- **数据格式**: JSON格式，包含传感器数据和控制命令

### 3.5 核心控制逻辑

#### 控制中心

- **驱动文件**: `src/control_center.rs`
- **功能**:
  - 数据收集和处理
  - 执行器控制逻辑
  - 定时任务管理
  - 状态机实现

## 4. 硬件连接

### 4.1 ST7735S屏幕 (SPI)

- **SCL (SCK)** -> PA5
- **SDA (MOSI)** -> PA7
- **RES (Reset)** -> PA2
- **DC (Data/Command)** -> PA4
- **CS (Chip Select)** -> PA3

### 4.2 BH1750光照传感器 (I2C)

- **SCL** -> PB6
- **SDA** -> PB7

### 4.3 DH11温湿度传感器 (GPIO)

- **DATA** -> PB11

### 4.4 土壤湿度传感器 (ADC)

- **DATA** -> PA0

### 4.5 执行器 (GPIO)

- **水阀** -> PB12
- **风扇** -> PB13
- **灯光** -> PB14
- **蜂鸣器** -> PB15

### 4.6 UART通信

- **TX** -> PA9
- **RX** -> PA10

## 5. 软件架构

### 5.1 任务调度

项目使用 Embassy Executor 进行任务调度，主要任务包括：

1. **control任务**: 数据收集和处理
2. **sub_control任务**: 执行器控制
3. **dht11_task**: 温湿度数据采集
4. **bh1750_read**: 光照数据采集
5. **soil_task**: 土壤湿度数据采集
6. **uart_tx**: UART数据发送
7. **uart_rx**: UART数据接收
8. **display_task**: 显示屏刷新

### 5.2 数据通信

项目使用 Embassy Sync Channel 进行任务间通信，主要通信通道包括：

- **DHT11_CHANNEL**: 温湿度数据通道
- **BH1750_CHANNEL**: 光照数据通道
- **SOIL_CHANNEL**: 土壤湿度数据通道
- **TX_CHANNEL**: 发送数据通道
- **RX_CHANNEL**: 接收数据通道

### 5.3 数据格式

项目使用 JSON 格式进行数据通信，主要数据格式包括：

#### 传感器数据格式

```json
{
  "type": "data",
  "temp": 25,
  "humi": 60,
  "soil": 350,
  "lux": 500.0,
  "water": 0,
  "light": 1,
  "fan": 0,
  "buzzer": 0
}
```

#### 控制命令格式

```json
{
  "type": "cmd",
  "target": "water",
  "action": "on",
  "time": 0
}
```

## 6. 核心功能实现

### 6.1 传感器数据采集

传感器数据采集采用异步任务实现，每个传感器有独立的采集任务。采集到的数据通过通道传递给控制中心进行处理和发送。

### 6.2 执行器控制

执行器控制采用状态机实现，支持以下控制方式：

- **开关控制**: 直接控制设备的开关状态
- **脉冲控制**: 控制设备开启一定时间后自动关闭

### 6.3 显示功能

显示屏任务定期更新传感器数据，支持中文和ASCII字符显示，使用自定义中文字库实现中文显示功能。

### 6.4 UART通信

UART通信实现了数据发送和接收功能，支持JSON格式的数据传输，用于与外部设备进行通信。

## 8. 开发说明

### 8.1 调试

项目使用 `defmt` 和 `defmt-rtt` 进行调试，需要配合支持 RTT 的调试工具使用。

### 8.2 配置

项目配置主要在 `src/config.rs` 中进行，包括时钟设置、中断绑定等。

### 8.3 扩展

项目设计支持模块化扩展，可以方便地添加新的传感器和执行器。

## 9. 注意事项

1. 确保硬件连接正确，避免短路和反接
2. 编译时需要安装正确的 Rust 工具链
3. 烧录程序需要使用支持 STM32F103 的调试器
4. 传感器采集和执行器控制有一定的时间延迟，需要合理设置采样频率
5. 系统资源有限，需要注意内存和栈的使用

## 10. 总结

本项目实现了一个完整的 IoT 环境监测和控制系统，具有以下特点：

- 基于 Rust 和 Embassy 异步框架，代码安全可靠
- 模块化设计，便于扩展和维护
- 支持多种传感器和执行器
- 实现了完整的数据采集、处理和控制功能
